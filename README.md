# FITIA Student Express

FITIA Student Express es un prototipo web estático inspirado en una experiencia de nutrición sencilla y accesible, adaptada a la vida universitaria. Ayuda a planear comidas rápidas, llevar un registro básico y organizar compras de acuerdo con un presupuesto personal.

## ¿A quién va dirigido?

A estudiantes universitarios que tienen poco tiempo para cocinar y necesitan cuidar sus gastos. La propuesta prioriza recetas rápidas, ingredientes económicos y medidas caseras para que planear una comida sea práctico.

## Funcionalidades

- **Inicio:** resumen del progreso diario y accesos rápidos a las secciones.
- **Recetas:** búsqueda por ingredientes disponibles, filtro de recetas de menos de 15 minutos, medidas caseras y preparación paso a paso.
- **Información nutricional abierta:** consulta de calorías, proteínas, carbohidratos y grasas sin bloqueos de suscripción.
- **Progreso:** registro diario de comidas y seguimiento de macronutrientes.
- **Compras:** lista por categorías, categorías personalizadas, costos estimados y un presupuesto editable que muestra el saldo disponible.
- **Cuenta local:** formularios de inicio de sesión y creación de cuenta para separar los datos en el navegador.
- **Diseño adaptable:** interfaz móvil y de escritorio con navegación accesible.

## Tecnologías

El proyecto usa HTML5, CSS3 y JavaScript. No requiere instalación de dependencias ni un proceso de compilación.

## Nota sobre las cuentas y los datos

Este proyecto es una demostración estática: no tiene servidor de autenticación ni sincronización en la nube. Las cuentas, comidas, presupuesto y lista de compras se guardan en el almacenamiento local del navegador y no se comparten entre dispositivos. No uses contraseñas reutilizadas ni guardes información sensible. Borrar los datos del navegador puede eliminar la información guardada.
